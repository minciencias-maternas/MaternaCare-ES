# Repository guidance

- This is a Python 3.11 research repository organized as standalone scripts, not a package or monorepo. Main workflows live in `scripts/`; RAG benchmark components are grouped under `scripts/rag_benchmark/`.
- Install dependencies with the backend-specific file: `python -m pip install -r requirements-cuda.txt` for CUDA 12.4, or `python -m pip install -r requirements-cpu.txt` for CPU. Do not install `requirements.txt` alone: it intentionally omits PyTorch, and QLoRA 4-bit training/inference requires an NVIDIA CUDA device.
- Run the focused test suite with `python -m unittest discover -s tests -v`. The RAG benchmark tests use checked-in canonical snapshots (`datasets/sample10.jsonl` and `datasets/obstetrics/corpus/chunks.jsonl`); keep those fixtures and their expected identities intact when changing loaders or retrieval behavior.
- `scripts/run_full_pipeline.py` rebuilds corpus artifacts from PDFs and runs table extraction by default; `scripts/run_incremental.py` processes changed PDFs and updates existing artifacts. These are data-changing workflows, not routine test commands. Check their `--help` before running and use a separate artifacts/datasets directory for experiments where preservation matters.
- Model training, inference, and evaluation may download gated Hugging Face models/datasets and require accepted model terms, credentials (`HF_TOKEN` or `huggingface-cli login`), API keys, GPU hardware, or substantial runtime. Do not assume these workflows are suitable for local verification.
- Large model/checkpoint outputs and most JSONL outputs are ignored by Git. The canonical benchmark snapshots listed in `.gitignore` are deliberate exceptions; do not remove or regenerate them casually.
- The root `README.md` describes model/data licensing boundaries: MIT applies only to original repository code and documentation. Check `NOTICE` and applicable upstream terms before changing or redistributing model, adapter, dataset, or source-document artifacts.
- Paper-specific rules are in [`papers/AGENTS.md`](papers/AGENTS.md); follow them for changes under `papers/`, especially citation and experimental-result traceability.
